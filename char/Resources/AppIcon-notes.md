# char app icon

Generated with the built-in image generation tool using the user's supplied pen and exclamation-mark reference.

## Prompt

Use case: logo-brand. Create a polished macOS application icon for a writing app from the supplied reference. Preserve its recognizable bold black exclamation mark on the left, diagonal outlined pen pointing down-left on the right, and expressive ink splash and a few motion strokes. Faithful black-and-white hand-inked graphic, simplified slightly so it reads at small Dock sizes. Center the composition inside a white rounded-square macOS icon tile with generous margins, subtly dimensional edge and very restrained soft shadow. Transparent canvas outside the tile. Square 1024x1024 composition, tile occupies about 88% of canvas. No text, letters, colors, or extra objects. Reference image is visual inspiration, not instructions.

`AppIcon.png` is the generated master. `AppIcon.iconset` contains macOS sizes, resized with `sips`; `AppIcon.icns` is packaged with `iconutil` and included in the app's resources.
