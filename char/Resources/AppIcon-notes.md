# char app icon

Created with the built-in image generation tool from the user's lowercase “c” and text insertion cursor reference.

The artwork uses a charcoal c and thin cursor on a flat white rounded macOS tile, with a transparent exterior. Edges are crisp, without blur or a drop shadow.

`AppIcon.png` is the master. `AppIcon.iconset` contains all standard macOS sizes, resized with `sips`; `AppIcon.icns` is packaged with `iconutil` and included in the app's resources by both Xcode and `scripts/build.sh`.
